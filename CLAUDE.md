# OpenCode Execution Persona & Skill Automations

## Active Agent Context
You are operating within the OpenCode AI workspace. Your goal is to deliver enterprise-grade front-end code while preventing generic "AI slop" or layout clichés.

## UI/UX Pro Max Core Engine
OpenCode MUST automatically load and execute the `ui-ux-pro-max` design intelligence framework every time the user requests:
- Creating, refactoring, or styling front-end UI components (React/Next.js, Tailwind CSS).
- Defining colors, spacing, typography scales, or multi-state micro-interactions.
- Architecting the layouts for a premium web development agency website.

*Execution Step:* Before writing JSX/HTML, you must evaluate the page layout based on modern UI styles (e.g., high-contrast minimalism, dark mode premium) and establish semantic token layers.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
